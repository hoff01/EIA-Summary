EIA SUMMARY - WINDOWS

Extract anywhere, for example %USERPROFILE%\Documents\EIA-Summary.
Scripts use their own folder as the root. Do not copy .venv between computers.

1. Install Python 3.11+ and sign into classic desktop Outlook.
2. Double-click RUN_EIA_SUMMARY_DASHBOARD.bat. It handles environment setup,
   dependency installation and the release workflow automatically.
3. On first use, enter recipients when prompted. They are saved only locally.

No separate setup step is required. SETUP_WINDOWS.bat is an optional setup-only
button. scripts\build_latest.bat creates a preview without sending email.
RUN_EIA_SUMMARY_DASHBOARD.bat -ShowDecision checks the schedule without sending.

Start early. It waits for the official Eastern release time (usually 10:30),
then polls every 5 seconds for up to 2 minutes. PDF rendering occurs only
after the expected week is ready. Classic Outlook opens automatically if needed.

scripts\install_windows_task.bat installs the 10:28 Eastern scheduled start.
Reinstall after moving the project or changing the computer's time zone.
scripts\send_test_email.bat sends a real email to your local recipients.

Sulfur stock and production boxes show current, W/W and Y/Y.
Production is PADD-level; weekly sub-PADD production is not published.
Exports show the weekly total only; EIA publishes no weekly sulfur split.

Keep local receipts in logs\ when transferring an existing installation.
They and recipient lists are excluded from GitHub.
Stats PNG project: https://github.com/hoff01/EIA-Stats-Puller.
See README.md for data sources and maintenance commands.
